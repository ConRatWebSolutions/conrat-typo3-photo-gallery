# Security policy

## Supported versions

| Version | TYPO3 | Supported |
|---|---|---|
| 3.x | 14.3 | yes |
| 2.x | 13.4 | no (not published) |

## Reporting a vulnerability

Please do **not** open a public GitHub issue for security problems.

Report them privately, either via GitHub's
[private vulnerability reporting](https://github.com/ConRatWebSolutions/conrat-typo3-photo-gallery/security/advisories/new)
or by e-mail to info@conrat.de. Include the affected version, steps to reproduce and, if possible, a proposed fix.

We confirm receipt within a few working days and coordinate a fix and release with you. For vulnerabilities that
affect published TER versions we follow the [TYPO3 security team process](https://typo3.org/help/security-advisories).
